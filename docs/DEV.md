# Development
## Useful commands
### Daytime
`/time set day`
### Spectator Mode
F3 + n  

Use the mousewheel to speed up flying around
### Item IDs
F3 + h
### Generating Chunks
`/neoforge generate start ~ ~ ~ 100 true`  

`/neoforge generate stop`
### Locating Structures
`/locate structure <mod:id>`  

Then click the coordinates it provides to teleport to it
### Teleporting to Nether/End
Nether - `/execute in minecraft:the_nether run tp @s 0 120 0`  
End - `/execute in minecraft:the_end run tp @s 100 80 0`  
Back to Overworld - `/execute in minecraft:overworld run tp @s 0 80 0`
