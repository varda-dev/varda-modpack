Varda Server

Extract this zip into a fresh folder, then run `run.sh` on Linux/macOS or `run.bat` on Windows.

The first launch will create `eula.txt` and stop if you have not accepted the Minecraft EULA yet.
If needed, open `user_jvm_args.txt` to adjust memory settings.

Keep this server package matched with the same Varda modpack version on the client.
